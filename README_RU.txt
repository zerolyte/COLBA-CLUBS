COLBA CLUBS — две отдельные панели с общей базой данных

ЧТО ВНУТРИ
- app.py — сервер и общая база данных SQLite
- Панель оператора: http://127.0.0.1:5000/operator/login
- Кабинет пользователя: http://127.0.0.1:5000/user/login

ЗАПУСК НА WINDOWS
1. Установите Python 3.10 или новее.
2. Распакуйте архив в отдельную папку.
3. Откройте CMD в этой папке.
4. Выполните: py -m pip install -r requirements.txt
5. Выполните: py app.py
6. Откройте в браузере: http://127.0.0.1:5000

ПЕРВЫЙ ВХОД ОПЕРАТОРА
Логин: admin
Пароль: ChangeMe2026!

СРАЗУ ПОСЛЕ ПЕРВОГО ЗАПУСКА
Поменяйте пароль администратора и секретный ключ перед публикацией в интернете.
В этой демонстрационной сборке смена пароля администратора через интерфейс ещё не реализована.
Оператор создаёт каждому ученику уникальные логин и пароль в своей панели.
Пользователь входит в отдельный кабинет и может только просматривать статистику.
Оператор редактирует клубы, общие баллы клубов, личные баллы учеников и учётные записи. В кабинете ученика отдельно показываются его личные баллы и общие баллы клуба.

ВАЖНО
Это локальная версия для запуска на одном компьютере. Чтобы входить с разных устройств,
нужно развернуть сервер на хостинге и настроить HTTPS, резервные копии и секретный ключ.
Не используйте демонстрационные данные и пароль в реальной публичной системе.
